# ระบบสำรวจความประสงค์เข้าร่วมการแข่งขันกีฬา

กีฬานักเรียนมัธยมศึกษาจังหวัดชัยภูมิ ครั้งที่ 51 ปีการศึกษา 2569 (กีฬานักเรียนโซนหุบเขา)

แต่ละโรงเรียนแจ้งล่วงหน้าว่าจะส่งกีฬาอะไร ประเภทไหน รุ่นอายุใด เพื่อให้ฝ่ายจัดการแข่งขันนำข้อมูลไปแบ่งสายแบบคร่าวๆ
ระยะนี้ **ยังไม่ส่งรายชื่อนักกีฬา** ระบบผูกกับ "ทีมของโรงเรียน" ไม่ใช่ตัวบุคคล จึงเปลี่ยนตัวผู้เล่นหน้างานได้โดยไม่ต้องแก้ในระบบ

## หน้าในระบบ

| หน้า | ไฟล์ | สถานะ | ผู้ใช้ |
| --- | --- | --- | --- |
| แจ้งความประสงค์ | `survey.html` | ใช้งานจริงได้ | ครูผู้ประสานงานโรงเรียน (รหัสโรงเรียน + PIN 6 หลัก) |
| สรุปความประสงค์ | `summary.html` | ใช้งานจริงได้ | สาธารณะ: จำนวนต่อรายการ ประมาณการสาย ส่งออก Excel |
| ผู้ดูแลระบบ | `admin.html` | ใช้งานจริงได้ | ฝ่ายจัด 1–3 คน: วันเปิด–ปิดรับ ออก PIN แก้แทนโรงเรียน |
| จัดการรายการแข่งขัน | `catalog.html` | ใช้งานจริงได้ | ทีมแอดมิน: เพิ่ม แก้ไข ปิดรับชนิดกีฬาและรายการแข่งขัน |
| ต้นแบบจัดการแข่งขัน | `competition.html` | ต้นแบบ ข้อมูลสมมติ | ผู้บริหาร/กรรมการ: ตารางแข่งขัน + ตารางเหรียญรวม |

## เทคโนโลยี (ค่าใช้จ่าย 0 บาท)

- หน้าเว็บ: HTML + JavaScript ล้วน ไม่ต้อง build วางบน **GitHub Pages** ได้ทันที
- ฐานข้อมูล: **Supabase** แผนฟรี (PostgreSQL) เรียกผ่าน REST API ไม่ต้องโหลดไลบรารีเพิ่ม
- ไม่ใช้ Google Apps Script และไม่ต้องล็อกอินบัญชี Google ใดๆ
- ถ้ายังไม่ตั้งค่า Supabase ระบบจะเปิดใน **โหมดสาธิต** (ข้อมูลสมมติ เก็บในเบราว์เซอร์) — ใช้นำเสนอที่ประชุมได้เลย

## ลองใช้บนเครื่องตัวเอง

ดับเบิลคลิก `index.html` ได้เลย หรือเปิดผ่านเว็บเซิร์ฟเวอร์จำลอง:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

โหมดสาธิต: เข้าหน้าแจ้งความประสงค์ด้วยรหัส `CYP001` PIN `111111` · หน้าผู้ดูแลใช้รหัสผ่าน `admin`

## ลำดับสาธิตในที่ประชุม 10 พ.ย. 2569 (ประมาณ 10 นาที)

1. หน้าแรก: เล่าโจทย์ — เก็บแค่ความประสงค์ ไม่เก็บรายชื่อ จึงไม่ขัดกับการเปลี่ยนตัวหน้างาน
2. แจ้งความประสงค์: เข้าด้วย `CYP001` / `111111` ติ๊ก 2–3 รายการ กดบันทึก (ทำบนมือถือให้ดูยิ่งดี)
3. สรุปความประสงค์: ชี้จำนวนต่อรายการ ประมาณการสาย/จำนวนนัด และปุ่มส่งออก Excel
4. ผู้ดูแล: ตั้งวันปิดรับ ออก PIN ใหม่ แก้แทนโรงเรียน
5. ต้นแบบจัดการแข่งขัน: ตารางแข่งขันและตารางเหรียญ — ภาพของระยะต่อไป
6. ขอมติ: วันเปิด–ปิดรับ, ผู้ยืนยันรายการกีฬา/รุ่นอายุ, จะทำระบบส่งรายชื่อ/บันทึกผลในระยะต่อไปหรือไม่
